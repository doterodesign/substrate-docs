Substrate is a computed design system framework that replaces static token libraries with mathematical intent. Instead of hand-authoring color ramps, type scales, and spacing values, you declare what your brand *means* — a primary hue, a base space unit, a type size, a scale ratio — and Substrate calculates every downstream token value using OKLCH color space and an APCA contrast solver. The result is a complete, always-accessible token set output for Web (CSS variables), iOS (Swift), and Android (Kotlin).

## How It Works

Substrate's build pipeline turns brand intent into platform-ready, accessible tokens in three steps.

<Steps>
  <Step title="Declare your brand intent">
    Write a `substrate.config` file that captures your brand's color hue and chroma, base space unit, type size unit, scale ratio, and motion unit. This is the only file you author by hand.
  </Step>
  <Step title="Run the compiler">
    Substrate reads your config and calculates every token value — color ramps, contrast-safe foregrounds, spacing scales, type scales, and motion values — using OKLCH interpolation and APCA contrast solving.
  </Step>
  <Step title="Import platform output">
    Substrate emits a CSS variables file for Web, a Swift constants file for iOS, and a Kotlin object for Android. Drop the output into your project and start using tokens immediately.
  </Step>
</Steps>
