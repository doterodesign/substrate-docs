Substrate uses APCA — the Advanced Perceptual Contrast Algorithm — to compute the lightness of every foreground color token at build time. The result is a system where every on-color token is mathematically guaranteed to be legible against its paired background surface. You never need to run a contrast checker manually because contrast is enforced as part of the build.

## What Is APCA?

APCA was developed by Andrew Somers and models how human vision perceives contrast between text or foreground elements and their background more accurately than the WCAG 2.x ratio formula. The legacy WCAG 2.x formula treats light and dark colors symmetrically and operates in sRGB luminance, which doesn't reflect how the eye actually adapts to luminance differences across the lightness range. APCA accounts for the spatial frequency of text (size and weight), the direction of polarity (light-on-dark vs. dark-on-light), and the non-linear response of human vision — producing contrast scores that align much more closely with perceived readability.

## Why Substrate Uses APCA

Substrate's token model separates hue and chroma (your brand intent) from lightness (a derived value). When you specify a `primary` color with `hue: 160` and `chroma: 0.18`, you are not specifying how light or dark that color is. Substrate solves for lightness by asking: *what lightness value, at this hue and chroma, produces the required Lc score against the current surface?* That calculation uses the APCA formula. The answer changes across modes — your primary color is lighter in dark mode and darker in light mode — but the contrast guarantee is identical in every case.

## Lc Scores

APCA uses an Lc (lightness contrast) scale instead of a ratio. Lc values are directional: a positive Lc score indicates a dark foreground on a light background (standard polarity), and a negative Lc score indicates a light foreground on a dark background (reverse polarity). Substrate normalizes these to absolute values when applying targets.

| Lc | Use case |
|---|---|
| Lc 15 | Decorative / non-text elements |
| Lc 30 | Large text (18px+ bold) |
| Lc 45 | Normal-weight large text |
| Lc 60 | Body text minimum (APCA floor; Substrate defaults to Lc 70) |
| Lc 75 | Small text, high importance |
| Lc 90 | High-contrast mode minimum |

## Default Contrast Targets

Substrate applies these Lc targets when computing foreground token lightness:

| Token role | Default Lc target |
|---|---|
| `--color-on-surface` (body text) | Lc 70 |
| `--color-on-surface-subtle` (muted text) | Lc 45 |
| `--color-on-primary` | Lc 75 |
| `--color-on-error` | Lc 75 |
| High-contrast mode (all foreground tokens) | Lc 90 |

## Adjusting Contrast Targets

You can raise or lower the default targets for specific roles using the `contrast-targets` field in your brand config. Raising a target produces higher-contrast foreground colors; lowering it produces subtler ones. You cannot set any target below Lc 30 — Substrate enforces this floor to prevent illegible output.

```json
{
  "brand": "acme",
  "contrast-targets": {
    "body-text": 75,
    "muted-text": 55
  }
}
```

<Warning>
Lowering `body-text` below Lc 60 or `muted-text` below Lc 30 may produce text that is difficult to read for users with low vision. Only lower targets when you have a specific, justified reason — not to achieve a particular aesthetic.
</Warning>

## APCA Comments in Generated CSS

Every foreground token in the generated CSS includes its solved Lc score as an inline comment. Use these comments to audit your token set, verify targets were met, and communicate contrast decisions in code review.

```css
:root[data-theme="light"] {
  --color-on-surface: oklch(12% 0.02 210); /* APCA Lc 71 */
  --color-on-surface-subtle: oklch(42% 0.02 210); /* APCA Lc 47 */
  --color-on-primary: oklch(99% 0.01 160); /* APCA Lc 76 */
  --color-on-error: oklch(98% 0.01 25); /* APCA Lc 75 */
}

:root[data-theme="dark"] {
  --color-on-surface: oklch(94% 0.02 220); /* APCA Lc 72 */
  --color-on-surface-subtle: oklch(64% 0.02 220); /* APCA Lc 46 */
  --color-on-primary: oklch(8% 0.01 160); /* APCA Lc 77 */
  --color-on-error: oklch(6% 0.01 25); /* APCA Lc 75 */
}
```

## High-Contrast Mode

In `high-contrast` and `high-contrast-dark` modes, Substrate overrides all foreground Lc targets to Lc 90, regardless of your `contrast-targets` config. This ensures that users who opt into high-contrast mode via their OS or your UI receive a meaningful accessibility uplift across every token in the system.

<Note>
APCA is the recommended contrast algorithm for WCAG 3.0, which is currently in development. Substrate adopts it now so your design system is future-ready — when WCAG 3.0 becomes the standard, your tokens will already meet it.
</Note>
