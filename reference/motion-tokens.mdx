Motion tokens are derived from `motion-unit`, the base animation duration in your brand config. Each `--motion-*` duration token is a named multiple of that unit, giving you a consistent vocabulary for communicating the weight and importance of transitions. Easing tokens are fixed cubic-bezier curves selected for common interaction patterns. Together, the duration and easing tokens ensure that your UI moves with coherent timing — fast micro-interactions use short durations and snappy easings, while large layout changes use longer durations and gentler curves.

## Duration Tokens

| Token | Multiplier | Value (100ms unit) | Use |
|---|---|---|---|
| `--motion-instant` | 0 | 0ms | State changes that should never animate |
| `--motion-fast` | 1× | 100ms | Micro-interactions, tooltips |
| `--motion-normal` | 2× | 200ms | Most UI transitions |
| `--motion-slow` | 3× | 300ms | Larger element transitions |
| `--motion-slower` | 5× | 500ms | Page-level transitions |

## Easing Tokens

| Token | Curve | Use |
|---|---|---|
| `--ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | General-purpose |
| `--ease-enter` | `cubic-bezier(0, 0, 0.2, 1)` | Elements entering the screen |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | Elements leaving the screen |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Playful bounce |

The `--ease-enter` and `--ease-exit` curves are asymmetric by design. Elements enter slowly and decelerate, drawing the eye toward them. Elements exit quickly and accelerate, stepping out of the way without demanding attention.

## Usage Example

Combine a duration token with an easing token in your CSS `transition` shorthand:

```css
.button {
  transition: background-color var(--motion-fast) var(--ease-standard),
              transform var(--motion-fast) var(--ease-spring);
}

.modal {
  transition: opacity var(--motion-normal) var(--ease-enter),
              transform var(--motion-normal) var(--ease-enter);
}
```

<Note>
When `prefers-reduced-motion: reduce` is active, all duration tokens except `--motion-instant` resolve to `0ms`. Build your components to handle instant transitions gracefully — never rely on animation timing for layout correctness or to delay content visibility.
</Note>
